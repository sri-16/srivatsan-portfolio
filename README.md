# Srivatsan C — Developer Portfolio

A responsive personal portfolio made with HTML, CSS and vanilla JavaScript.

## Features
- Responsive mobile-first layout
- Dark/light theme toggle
- Mobile navigation menu
- Smooth scrolling
- Interactive project detail dialogs
- Contact section and email-copy interaction
- Accessible labels and reduced-motion support

## Open in Visual Studio Code
1. Extract `developer_portfolio.zip`.
2. Open Visual Studio Code.
3. Choose **File → Open Folder** and select the extracted `developer_portfolio` folder.
4. Open `index.html`.
5. For the easiest preview, install the **Live Server** extension by Ritwick Dey.
6. Right-click `index.html` and choose **Open with Live Server**.

You can also double-click `index.html` to open it in a browser, but Live Server is more convenient while editing.

## Personalise before publishing
- In `index.html`, check the name, course, college, introduction, and social links.
- Replace the generic LinkedIn and GitHub links with your own profile URLs.
- In `script.js`, set `PORTFOLIO_EMAIL` to the email address you want to display.
- The portfolio card is the starter project. The circuit lab and security notes are clearly marked as future ideas, not completed projects.
- Replace or remove any skills you have not started learning.

## Publish using GitHub Pages
1. Create a public repository on GitHub, for example `srivatsan-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a little while and refresh the Pages settings. GitHub will show your live website URL.

## Important
This is a static website. It does not have a backend or a working contact form. The social links are generic placeholders until you replace them. The Google Fonts import needs an internet connection; the site will still work with fallback fonts.
